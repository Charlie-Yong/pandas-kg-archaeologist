五人使用Codex，一人使用WorkBuddy等工具；一台Mac、五台Windows。各自本机开发，在feat/p1至feat/p6提交PR，P1组织程序与独立GPT/DeepSeek检查后合并main，接收方同步继续。无需同时在线。

生产抽取和回答默认DeepSeek API；所有内容审核使用GPT或DeepSeek。P6独立生成并冻结模型参考标注、再评估正式预测，报告注明模型评审性质。密钥各自在本机配置，不上传仓库。

研究范围：pandas一个仓库，v1.3.5/v1.5.3/v2.0.0源码快照、8–12个API，先以DataFrame.append/Series.append试跑。11月11日期中每组五分钟；内部12月20日前形成期末候选交付。
