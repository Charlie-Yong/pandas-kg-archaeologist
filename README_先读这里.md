# 先读这里

这是知识图谱课程项目的 **v4.1.2 执行规划**，已替代原来的两份规划。

## 发给成员的方法

1. 由组长把六位成员对应到 P1–P6。
2. 每位成员只拿下面对应的**一份文件**，完整交给自己的 AI。
3. AI 按文件先检查能力和已有工作，再实际推进；成员协助账号授权、预算和设备操作，理解成果并准备课堂展示；内容审核交GPT/DeepSeek。

| 角色 | 直接交给该成员 AI 的文件 |
|---|---|
| P1 数据与集成 | [P1 执行文件](P1_数据与集成_给成员AI.md) |
| P2 图谱与查询 | [P2 执行文件](P2_图谱与查询_给成员AI.md) |
| P3 代码与演化 | [P3 执行文件](P3_代码与演化_给成员AI.md) |
| P4 模型与知识抽取 | [P4 执行文件](P4_模型与知识抽取_给成员AI.md) |
| P5 原型与汇报 | [P5 执行文件](P5_原型与汇报_给成员AI.md) |
| P6 标注与实验 | [P6 执行文件](P6_标注与实验_给成员AI.md) |

文件内已经写明 AI 的身份和第一步，不需要成员另写专业提示词。每份包含同一版完整公共契约、自己的工作单和个人报告责任，不依赖本聊天或另一成员的文件。
